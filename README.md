# Claude IA: Do Pedido ao Arquivo Pronto, página do livro

Página online do livro de Kelvin Baumhardt Biffi (YellowKode Academy): os materiais de demonstração de cada tarefa, os pedidos para copiar, as respostas do Claude sem edição, os arquivos que ele gerou (Word, Excel, PowerPoint), a conferência de cada teste e o anexo com o que muda no produto.

Página: https://yellowkode-academy.github.io/claude-ia-do-pedido-ao-arquivo/

As empresas, pessoas e números dos materiais de demonstração foram criados para os exercícios e não existem. Claude é uma marca da Anthropic; este livro e esta página são independentes e não têm relação com a empresa.
